# Expense Tracker - Java Project

Java, JSP/Servlet, Maven aur MySQL se bana hua Expense Tracker.

## Features
- Login / Register
- Expense Add Karna
- Expense List Dekhna
- Expense Delete Karna
- MySQL Database me Save Hota Hai

## Technologies Used
- Java
- JSP / Servlet
- Maven
- MySQL
- Tomcat Server

## Kaise Chalaye?
1. MySQL me `database` folder wali SQL file chalao
2. Project ko Eclipse / VS Code me kholo
3. Tomcat Server pe Run karo
4. Browser me `localhost:8080` pe kholo
